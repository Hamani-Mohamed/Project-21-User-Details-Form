# 📝 User Details Form

## 📖 About
A dark-themed form that lets users save and manage their name, email, and favourite colour using the browser’s local storage.

## ✨ Features
* 💾 **Save details:** Store form data in local storage.
* 📂 **Load details:** Display saved information.
* 📧 **Delete email:** Remove only the saved email.
* 🧹 **Clear storage:** Clear all local storage data.
* 🎨 **Gold-and-black design:** Styled form with a colour picker.

## 🛠️ Built With
* 🌐 HTML
* 🎨 CSS
* ⚡ JavaScript
* 💽 Browser Local Storage
